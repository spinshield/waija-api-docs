# Waija API Docs

Editable Casino API documentation app. Visual language matches [WAIJA house / Floor](https://floor.waijafive.com/). Content follows [documentation.waija.com](https://documentation.waija.com/).

## Live

- GitHub Pages: https://spinshield.github.io/waija-api-docs/
- One-click Vercel: [![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/spinshield/waija-api-docs)

## Edit pages

- In the app: **Edit this page** (saved in the browser)
- In source: `content.js` → `pages[id].body` (Markdown)

## Local

Open `index.html` or run `npm start` and visit http://localhost:4173
